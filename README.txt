CineScript Pro｜映像作品制作支援ツール
======================================

■ GitHub Pagesへの公開
1. このZIPを展開します。
2. 「index.html」と「assets」フォルダをそのままGitHubリポジトリ直下にアップロードします。
3. Settings > Pages > Deploy from a branch > main / (root) を選択します。
4. 発行されたGitHub PagesのURLを開きます。

■ 単体HTML
別添の「CineScriptPro_単体.html」は画像素材もすべて内蔵したファイルです。
GitHub PagesへこのHTMLを index.html としてアップロードするだけでも動作します。

■ 基本操作
・絵コンテモード：左でシーン選択、中央でカットを縦に追加。サムネイルクリックで作画。
・右側のテキスト入力：ト書きは // +半角スペースで、台詞は選択した話者名とともに保存。
・キャンバスモード：デフォルト4枚・最大10枚のラスターレイヤーに作画。
・対応デバイスではペンタブレットの筆圧を使用。マウスでも描画可。
・Ctrl+Z（戻す）、Ctrl+YまたはCtrl+Shift+Z（やり直す）。
・カットカードまたは左のカット一覧はドラッグして同一/別シーンへ並び替え可。
・PNG/JPEG/WebPを現在のレイヤーに配置可能。

■ データ保存
・編集データはブラウザのIndexedDBに自動保存されます（利用可能な環境のみ）。
・JSON保存は画像の全レイヤー、台詞、ト書き、シーン、キャラクター情報を含みます。
・JSON読込でプロジェクトを再開できます。バックアップにはJSON保存を推奨。
・ブラウザのデータ削除やプライベートモードで自動保存データが失われる可能性があります。

■ 書き出し形式
・HTML：全カットをフル解像度の画像と台本付きで1ファイル化。印刷にも対応。
・TXT：全シーンと全カットのテキストを1つの台本として出力。
・PSDセット：カットごとに画像レイヤー、台本のラスターレイヤー、用紙背景を含むPSDを生成してZIP化。
  話者付きテキストは付属のscript.txtにも収録されます。
  ※PSDの文字は編集可能なテキストレイヤーではなくラスターレイヤーです。

■ 動作環境
Chrome / Edgeの最新版（JavaScript、Canvas、IndexedDB）を推奨。
インターネット接続や外部ライブラリは不要。ブラウザ内で処理されます。
キャンバスは960×540px（16:9）。画像・PSDの書き出しはカット数や描画内容によって容量が大きくなります。
